## 需求 v0.1 → v0.2 的主要变化

| 变化 | 说明 | 章节 |
|---|---|---|
| 合并模型 | “以新版为基础恢复旧版”改为“每处差异选择采用旧版或新版，默认新版” | §7 |
| 部署形态 | 纯浏览器本地处理；可发布到 Posit Connect，也可离线单文件使用 | §3 |
| 移动内容 | 识别移动，合成一个差异，一次选择 | §7.4 |
| 采用旧版的限制 | 含脚注、图片、超链接、域的片段，首版不可采用旧版 | §7.5 |
| 结构保护 | 分节、书签、域边界等结构不随片段删除 | §7.6 |
| 表格 | 列和合并单元格结构变化时，首版整表二选一 | §7.7 |
| 未比较可见性 | 占位符、检查范围面板、指纹提示 | §6.3 |
| 可选比较项 | 自动编号、目录、域可设置是否比较 | §6.4 |
| 文本规范化 | 空白、引号等差异默认显示，可分类隐藏 | §6.5 |
| 上下标、隐藏文字 | 上下标算内容；隐藏文字显示并比较 | §4.1、§6.1 |
| 处理状态与进度 | 三种状态、最终结果预览、保存审阅进度 | §8 |
| 界面语言、使用方式 | 英文界面；首版为个人使用 | §2 |
| 支持范围说明 | 单独的面向用户的支持范围文档 | `docs/Supported-Scope.md` |
| 导出细节 | 文件命名规则；打开时提示更新域 | §8.4 |
