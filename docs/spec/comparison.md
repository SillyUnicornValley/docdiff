# 比较规则

> 现行规则：什么算差异、差异怎么切分、怎么显示没有比较的内容。
> 每种 Word 元素的逐项状态见 §8。
> 对齐算法的技术细节见 [../implementation/stage2-design.md](../implementation/stage2-design.md) §3。

## 1. 内容与格式分开

- 内容比较只看文字和“承载内容的标记”。
- **上标、下标算内容**：`10⁶` 和 `106` 意思完全不同（决定 4）。
- **隐藏文字**显示（虚线标注）并参与比较（决定 11）。
- 加粗、斜体、下划线、颜色、字体、字号是格式，不参与内容比较。
- run 拆分、换行、分页位置不同，不算内容变化。

> **什么是 run**：Word 在文件内部把一个段落切成若干段存放，每一段是一串格式完全相同的连续文字，叫一个 run。例如 “Patients take **10 mg** daily.” 存成 `Patients take `、`10 mg`（加粗）、` daily.` 三个 run。Word 还会在看不见的地方切开 run（在句中编辑过、拼写检查标记、接受修订后留下的切口、复制粘贴等），所以两份看起来一模一样的段落，内部切法可能不同。比较前先把同一段落里所有 run 的文字拼回整句，因此切法不同不算内容变化（验收标准 2）。

在内容视图中显示标题或表格，不代表正在检查它们的格式差异。例如两份文档的标题文字一致，但从 Heading 1 改成了 Heading 2：

- 内容比较不认为这是文字修改，不产生差异，也不能选择；
- 内容视图仍按各自的结构，用统一样式显示；
- 两侧段落旁显示提示 “⚑ Heading 1 → Heading 2”，顶部说明栏和检查范围面板列出所有级别变化；正文变成标题（或反过来）同样提示，如 “Body text → Heading 2”（决定 37）；
- 导出保留新版的级别，需要改回时导出后在 Word 中修改。

格式目前不检查（决定 47）：格式不同不产生差异，Formatting 标签页显示 “not checked”，不能写成“没有格式差异”。以后另做，见 §9。

## 2. 差异的粒度

### 2.1 规则

- 以**段落**为基本单位，相当于 VS Code 中的“行”（决定 1）。
- 表格内以**单元格**和**行**为单位。
- 每一对修改的段落是一个差异，段内用词级高亮显示具体变化（决定 14）。
- 连续新增的段落合成一个差异；连续删除的段落同样合成一个。
- 拆段、合段（一对多、多对一）是一个差异。
- 一对一修改的段落可以展开逐处选择（决定 42，G6）。
- 差异的边界由对齐算法决定，不提供手动配对。

### 2.2 差异的切分规则 G1–G12

引擎按下面的规则把改动切分成差异。这些规则在开发 Stage 2 时按开发判断定下；2026-10-09 用户用示例文档试用后全部确认（G6 见决定 35，其余见决定 36）。相关决定：1、14。

| # | 规则 | 例子 | 曾考虑的其他做法 |
|---|---|---|---|
| G1 | 每对修改的段落各为一个差异 | 01 中连续改了三段，显示为三处差异 | 连续的几处修改合成一处 |
| G2 | 连续新增（或连续删除）的段落合成一个差异 | 02 中新增“标题 + 一段正文”，只算一处差异 | 每段单独一处，可以分别取舍 |
| G3 | 新增（或删除）的一组遇到一级标题就另起一组 | 02 中新增的 “St. John's Wort” 与其后新增的一节 “Concomitant Medications” 分成两处 | 不按标题拆分 |
| G4 | 空段落单独成组，以便按“空段落”类别隐藏 | 新增“空段 + 正文”显示为两处差异 | 和相邻内容合成一处 |
| G5 | 同一位置只剩一段被删、一段新增时，合成一处“修改”，整段替换，只需选一次 | 06 中 “Compliance…” 改写为 “Adherence…” | 显示为一处删除加一处新增，分别取舍 |
| G6 | 一个段落里有多处改动时，整段是一个差异；默认整段取舍，也可以展开逐处选择（决定 42：一对一的修改段落、2 处以上变化、段落只含文字） | 01 中 “Weeks 2, 4, 8 and 12” 改成 “…12, 16 and 24”，改了两处：可以整段选，也可以只要新版加的 24 | 只能整段取舍（v0.5 以前的做法，决定 35）；按句选择（每句仍是完整原文，但 `e.g.`、`No. 5` 等可能断错句）。现在的逐处选择最灵活，但可能拼出不通的句子，选完请看最终结果预览 |
| G7 | 表格：单元格的修改按单元格取舍；连续增删的行合成一处（与 G2 一致）；列变化或合并结构变化时整表取舍 | 03 中剂量表的三处改动分别取舍；真实样例 DMP 中一张表连续删掉 41 行，算作几处差异，而不是 41 处 | 增删的行逐行取舍；见决定 6 |
| G8 | 同一位置的两张表，即使相似度不高（不低于 0.3），只要列数相同，也逐行比较，不显示为“删整表、加整表” | 真实样例 DMP 中 57 行的表改为 31 行 | 相似度低时显示为整表删除加整表新增 |
| G9 | 短段落只有在两份文件中各出现一次、文字完全相同时才认作移动（决定 32） | 13 号文档列表重新排序，显示为两处移动 | 短段落一律不认作移动；或允许相似的短段落 |
| G10 | 表格行第一格相同就配成同一行（决定 32） | 12 号 Glucose 行的单位和范围都改了，仍显示为一行内两个单元格的修改 | 只按整行相似度配对 |
| G11 | 整章移动拆成多处：标题和长段落各算一处移动，重复的 “Overview” 小标题显示为删除加新增 | 13 号文档 “Population” 一章移到前面，需要选择约 7 次 | 识别连续的移动，合成一处“整块移动” |
| G12 | 表格拆成两张：前半张逐行对齐，后半张显示为删除的行加新增的表 | 10 号文档 J 表 | 识别拆表，按行对齐两张表 |

讨论时建议用真实文档试用后再定：差异太碎，需要点很多次；差异太粗，又没法只要其中一部分。

## 3. 移动的内容

普通比较会把移动显示成两处互不相关的差异（一处删除、一处新增）。如果分别选择，可能导致内容重复（删除处选旧版、新增处保持新版）或丢失（反过来）。

规则（决定 7）：

- 识别“删除＋新增”中文字相同或高度相似的配对，标为“已移动”，合成**一个差异**。
  - 高度相似：相似度不低于 0.8。相似度 = 两边按相同顺序共有的词数 × 2 ÷ 两边的总词数（不区分大小写，不计空白和标点）。例如 10 个词的段落，移动时改了 2 个词以内（2×8 ÷ 20 = 0.8）仍算移动；改了 3 个词（0.7）则显示为一处删除和一处新增。段落越长，能容忍的改动越多。
  - 位置未变、只改了文字的段落配成“修改”，门槛较低（0.5）；移动在全文范围内找配对，门槛定得高，避免把用词相近但不相干的两段误配。
- 一次选择：采用旧版即放回原位置，采用新版即留在新位置。两处的显示同步变化。
- 两处可以互相跳转。
- 移动的同时修改了文字时，两处都显示词级差异；差异卡片上醒目标注 “✎ Moved and text changed”，空白一侧也注明 “text also changed”，避免误以为只是换了位置（决定 37）。
- 短段落（少于 5 词）只有文字在两份文件中各出现一次时才认作移动；重复出现的文字（如 “Not applicable.”）不认作移动（决定 32，G9）。

## 4. 表格

| 变化 | 能力 |
|---|---|
| 单元格文字修改 | 单元格级二选一 |
| 行新增或删除（无合并单元格跨越该行） | 行级二选一 |
| 列新增或删除、合并单元格结构变化、嵌套表格结构变化 | 整张表二选一，卡片标 “Whole-table choice” 并说明原因（决定 6） |
| 段落与表格互换 | 整块二选一 |

- 表格行按内容相似度配对，不按行号配对；第一格文字相同（且含字母）时直接配成同一行（决定 32，G10）。
- 整表二选一的原因：列和合并单元格的局部恢复牵涉每一行的单元格、列宽和合并跨度，任一处不一致，Word 就会把表格显示坏。
- 整表差异中，改动的单元格仍然高亮。

## 5. 未比较元素的可见性

“未比较”不代表“无差异”。对支持范围以外的元素，不能在结果中暗示已完成全面检查。

- **占位符**：内容视图中，未比较的元素在原位置显示占位符，例如 `[Image · not compared]`。脚注、尾注、文本框的内容在 Other parts 中比较，占位符只显示名称 `[Footnote 2]`，内容不同时标 “differs”。
- **Other parts 标签页**（决定 45、46）：脚注、尾注、页眉页脚（按节、按种类）、文本框逐项并排比较，带词级高亮；配对段落中的超链接地址、图片数据、文档属性、批注列出不同之处。只提示，不能选择，导出保留新版。
- **检查范围面板**：列出已比较的内容、只检测的元素、只显示的元素及各自数量，以及“Formatting: not checked”。
- **指纹提示**：对未比较元素做“相同／可能不同”的简单判断，不展示具体差异。适用于页眉页脚、脚注内容、图片、超链接地址、文档属性。
- **页眉页脚按节提示**（决定 17）：Word 的页眉页脚按节存放，每节最多有首页、奇数页（默认）、偶数页三种。
  - 逐节、逐种比较指纹，在检查范围面板中按节列出，例如“第 3 节 · 页眉 · 可能不同”。
  - 两版的节按共有内容配对，不按序号配对。只在某一版中存在的节，标为“仅新版有此节”或“仅旧版有此节”。
  - 有差异的节在内容视图中加标记：第 1 节标在文档开头，其余各节标在前一节的分节符处。各节都相同时不加标记。
- **批注**：新版批注在内容视图中显示位置标记 “Comment · 作者”；旧版批注也显示，灰色 “Old comment · 作者”（决定 46）。批注不产生差异；Other parts › Comments 逐条比较：按（作者、批注文字、锚定文字）相同 → 相同；作者和锚定文字相同 → 批注文字改了；作者和批注文字相同 → 锚定文字改了；其余为只在一边。

未比较的元素不应因此在导出时被自动删除。

## 6. 可选比较项

以下内容由 Word 自动生成或动态计算，提供独立的“是否比较”开关（决定 10）。打开后，差异只做提示，**不可选择**采用旧版或新版。

| 项目 | 默认 | 现状 | 说明 |
|---|---|---|---|
| 自动编号（列表、标题编号） | **开**，可在 View 中关闭 | 实现：编号不同时在编号旁标出 “№ 3. → 4.”，不产生差异卡片、不进导航；顶部说明栏和检查范围面板列出全部（决定 38） | 插入一条会使后续编号整体变化，所以可能较多。不能选择：编号由 Word 按列表结构自动计算，导出时写不进固定编号，导出保留新版编号。项目符号改为编号、手打编号改为自动编号也会标出 |
| 目录 | 关，目录区域折叠显示 | 实现开关 | 导出后需在 Word 中更新目录 |
| 日期、页码等域 | 关，只显示结果并标为域 | 实现开关 | 域结果会随打开时间、分页变化 |

手打的编号（例如 `1) `）是文字，按普通内容比较。

## 7. 文本规范化

以下几类细小的差异会被检测出来，**默认和其他差异一样显示、可以选择**（决定 9）。每处差异会标上类别，可以在 View 菜单里按类别隐藏：

| 类别 | 示例 |
|---|---|
| 空白 | 多个空格与一个空格、不换行空格、段首尾空格、软回车与空格 |
| 空段落 | 空段落数量增减 |
| 引号 | 直引号与弯引号 |
| 短横线 | `-` 与 `–`、`—` |
| 大小写 | `Week` 与 `week` |
| 手打编号 | 手打的 `1) ` 改为显示相同的自动编号 `1)`（仅在两者显示完全一致时归入此类，决定 23） |

隐藏某类差异只影响显示和导航。被隐藏的差异仍按默认值（新版）进入最终结果。一处差异中所有词级变化都属于被隐藏的类别时才整体隐藏，否则只去掉对应的高亮（A6）。

## 8. 元素逐项状态

| 状态 | 含义 |
|---|---|
| **比较** | 检出差异、高亮，可以选择 Use old / Use new |
| **只检测** | 只判断两版是否“可能不同”，不显示具体差异，需要到 Word 中查看 |
| **只显示** | 在视图中可见（常用占位符，如 `[Image · not compared]`），但不检出差异 |
| **不比较** | 目前不处理，见说明 |

不在“比较”状态的内容，都不能理解为“没有差异”。

| 元素 | 状态 | 说明 |
|---|---|---|
| 正文和标题文字 | **比较** | 词级高亮 |
| 拆段、合段 | **比较** | 显示为一处差异 |
| 移动的段落 | **比较** | 显示为一处 “Moved” 差异（§3） |
| 列表项文字 | **比较** | |
| 自动编号和项目符号 | 只提示 | 编号不同时标 “№”，不能选择（§6，决定 38）；插入一项不会让后面的项被标为修改 |
| 手打编号（如 `1) `） | **比较** | 是普通文字 |
| 表格单元格文字 | **比较** | |
| 表格行增删 | **比较** | |
| 表格列增删、合并单元格变化 | **比较**（整表） | 整张表一个选择（§4） |
| 嵌套表格 | **比较** | 结构变化时退回整表选择 |
| 上标、下标 | **比较** | 算内容：`10⁶` 和 `106` 是差异 |
| 隐藏文字 | **比较** | 用虚线下划线显示 |
| 空白、空段落、引号、短横线、大小写 | **比较** | 默认显示，每类都可在 View options 中隐藏（§7） |
| 超链接显示文字 | **比较** | |
| 超链接地址（URL） | 比较，只提示 | Other parts 列出配对段落中地址变了的链接（决定 45） |
| 内容控件 | **比较**（内部文字） | 控件属性不比较 |
| 目录 | 只显示 | 默认折叠；可打开比较（§6）。导出后在 Word 中更新域 |
| 日期、页码等域 | 只显示 | 可打开比较（§6） |
| 交叉引用 | **比较**（显示的结果） | |
| 脚注、尾注引用 | **比较**（标记位置） | |
| 脚注、尾注文字 | 比较，只提示 | Other parts 中逐条并排比较（决定 45）；含脚注的旧内容可以带回（决定 43） |
| 页眉页脚（含水印） | 比较，只提示 | 按节、按类型（首页、奇数页／默认、偶数页）配对，在 Other parts 中并排比较（§5） |
| 图片 | 只显示，只检测 | 占位符；配对段落中图片数据不同时在 Other parts 列出；含图片的旧内容可以带回（决定 43） |
| 图表、形状、SmartArt | 只显示 | 占位符；含这些的旧内容不能带回 |
| 文本框 | 只显示，内容比较只提示 | 占位符；内容在 Other parts 中比较 |
| 公式 | 只显示 | 占位符 |
| 嵌入对象 | 只显示 | 占位符 |
| 批注 | 比较，只提示 | 两版批注都显示标记；Other parts 逐条比较；导出保留新版批注，不带入旧版批注（§5，决定 46） |
| 文档属性（标题、主题、说明、关键词、类别） | 比较，只提示 | Other parts 列出不同的属性 |
| 标题级别 | 只提示 | 级别变化以 “⚑” 标出，不能选择（§1，决定 37） |
| 格式：段落样式、对齐、缩进、间距、列表类型、文字格式、表格样式 | 不检查 | Formatting 标签页显示 “not checked”（§9，决定 47）；导出保留新版格式 |
| 页面设置和分节布局 | 不比较 | 沿用新版 |

## 9. 格式检查（暂缓，决定 47）

格式目前不检查。v0.5.0 曾经做过只提示的格式检查（决定 44），后来撤回：用户本来就打算以后单独做格式检查；内容和格式基本互不相关，两种变化同时显示会让比较页面太拥挤。

以后的设想（到时再讨论细节）：

- 内容比较、格式比较各出一套结果；
- 用户可以选择只看内容比较结果、只看格式比较结果，或者两者同时显示（同时显示也要提供）。

撤回前的做法（比较哪些属性、按生效格式比较、只在共有的词上比较等）记录在 [stage5-design](../implementation/stage5-design.md) §4，以后可以参考。
