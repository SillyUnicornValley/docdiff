# 界面

> 现行规则：界面怎么呈现内容、有哪些操作、进度怎么保存。
> 界面决定 A1–A12 的记录见 [../decisions.md](../decisions.md) §2；使用说明见 [../user-guide.md](../user-guide.md)；发布前的手工验证见 [../dev guidance/release-checklist.md](../dev%20guidance/release-checklist.md)。

## 1. 内容呈现：保留结构，统一阅读样式

用户需要的不是纯文本视图，也不是逐页、逐像素复刻 Word，而是保留适合阅读的文档结构。

| 原文内容 | 对比界面呈现 |
|---|---|
| Heading 1 | 统一的一级标题样式 |
| Heading 2 / Heading 3 | 对应层级的标题样式 |
| 正文段落 | 统一的正文阅读样式 |
| 编号和项目符号列表 | 保留条目、编号或符号及层级；编号按 Word 规则计算后显示 |
| 表格 | 保留行列、合并单元格关系，以表格呈现 |
| 上标、下标 | 照原样显示，**并视为内容** |
| 加粗、斜体、下划线 | 照原样显示，但视为格式，不参与内容比较 |
| 未比较的元素 | 以占位符显示，例如 `[Image · not compared]` |

- 网页上的字体、字号、颜色、段落间距不要求与原文件逐项一致。两边使用同一套阅读样式，便于比较。
- 统一的是外观，不是结构：每段按各自原文的结构（标题级别、列表、表格）显示，不会为了两边一致而改变某一侧的结构。例如旧版 Heading 1、新版 Heading 2 时，左边显示为一级标题，右边显示为二级标题。
- 为对应内容对齐，允许在显示中加入空白，不向原文件插入空段落。不要求网页分页和换行位置与 Word 完全相同。

## 2. 选择文件

- 两个区域分别选择旧版、新版 .docx 文档；显示文件名及版本角色。
- 首页提供内置的示例文档对（testdocs 01–18），点击后用真实引擎比较；网址加 `?mock` 时显示原型的手写 mock 数据，仅供界面开发。
- 支持交换左右文件。已有选择记录时，交换前需确认，交换后选择清空。重新上传任一文件，同样需确认并清空选择。
- 显示已有修订的处理说明。
- 不支持的文件（.doc、加密文件等）给出明确提示；.doc 的提示写明在 Word 中另存为 .docx 的操作步骤（决定 33）。

## 3. 比较界面

| 区域或功能 | 内容 |
|---|---|
| 顶部 | 文件名、检查范围面板入口、三个标签页 Content／Formatting／Other parts（Formatting 显示 “not checked”，Other parts 带不同之处的数量）、处理进度、导出操作 |
| Formatting 标签页 | 只显示说明 “Formatting: not checked”：格式不检查，不代表格式相同（决定 47） |
| Other parts 标签页 | 批注、脚注、尾注、页眉页脚、文本框逐项列出；不同的项旧、新并排，带词级高亮；超链接地址、图片、文档属性列出不同之处；“Show in document” 跳到 Content 中该段并闪烁提示（决定 45、46） |
| 差异导航 | 上一处、下一处、下一处未处理、当前差异位置与总数 |
| 左侧 | 原始旧版内容，删除或被替换的部分高亮 |
| 右侧 | 原始新版内容，新增或替换后的部分高亮 |
| 中间窄栏 | 选择按钮（A5）；表格行内用单行按钮；手机上移到两栏上方 |
| 最终结果预览 | 按当前选择拼接后的结果；第三栏（Third column）和单栏（Preview only）两种方式都提供（A1） |
| 查看选项 | 同步滚动、折叠相同内容、仅看差异、按类别隐藏差异、可选比较项开关、编号标记 “№” 开关 |
| 逐处选择 | 可以逐处选择的修改段落，卡片上有 “▸ Choose per change (N)”；展开后每处变化一行：旧文字 → 新文字，配 Old／New 按钮。选了一部分旧版时状态为 “Mixed”，两侧不用的那几处变淡，最终结果预览中来自旧版的文字用琥珀色标出（决定 42） |
| 批量操作 | 选定一节（下拉选节，默认当前差异所在的节，显示每节的差异数和未处理数）全部采用旧版或新版；全部未处理项采用新版（A9） |

显示规则：

- 说明文字放进浮窗（决定 40）：主页面只放短标签，说明“是什么”；“为什么、怎么办”放进浮窗，标签旁加 ⓘ。鼠标移上去立即出现，键盘聚焦或点击（触屏）也能打开。影响结果正确性的警告（如单元格修订）仍在页面上保留短句。按钮的快捷键提示仍用浏览器自带提示。
- 左右两栏始终显示原始内容，不随选择变化（决定 3）。未处理的差异两侧都不淡化，卡片用虚线框；明确选择后才淡化放弃的一侧，并标明当前选择（A4）。
- 不只靠颜色表达状态：
  - 旧版一侧左边线为红色，带 `−` 号；新版一侧为绿色，带 `+` 号；移动为蓝色，带 `⇄` 号。
  - 被删除或替换的词加删除线，新增的词加下划线。
  - 差异卡片写明类型，例如 “Modified”、“Inserted”。
- 对齐：每个对齐单位是一行，左右两格同高，短的一侧用斜纹空白填充，并写明 “not in old”、“row not in new” 等。
- 空白类差异用可见符号显示：空格 `·`，不换行空格 `°`，软回车 `↵`；拆段、合段处显示 `¶`。只在空白差异处显示，不提供全文显示。
- 表格：纵向合并单元格用“去掉内部横线”近似显示；整表差异中改动的单元格仍高亮。
- 最终结果中来自旧版的内容用琥珀色底和 “FROM OLD” 标记。在 Preview only 中，点击左侧的差异编号可回到对照视图中的该差异。
- 同步滚动关闭时，两栏各自滚动，不插空白；重新打开时以左栏顶部的内容为锚点恢复位置。
- 脚注、尾注、文本框的占位符只显示名称（如 `[Footnote 2]`），内容不同时标 “differs”，内容在 Other parts 中比较（决定 45）。
- 新版批注在正文中显示位置标记 “Comment · 作者”；含新版批注的差异卡片注明 “Has a new-file comment”（A10）。旧版批注显示为灰色 “Old comment · 作者”（决定 46）。
- 标题级别变化：两侧段落旁显示紫色标记 “⚑ Heading 1 → Heading 2”；顶部说明栏显示 “⚑ N heading level change(s)”，点开检查范围面板逐条列出（决定 37）。
- 自动编号变化：编号着色，旁边显示 “№ 3. → 4.”；顶部说明栏显示 “№ N automatic numbering change(s)”，检查范围面板逐条列出；View 菜单 “Mark automatic numbering changes” 默认勾选，可取消（决定 38）。
- 移动且改了文字：差异卡片显示黄色标注 “✎ Moved and text changed”，紧凑模式在图标旁加 ✎（决定 37）。
- 页眉页脚可能不同的节，在正文中标 “§ Section n”（A12）。
- 工具内不支持直接编辑文字（决定 13）。

快捷键：`J` 下一处，`K` 上一处，`U` 下一处未处理，`1` 采用旧版，`2` 采用新版，`Ctrl+Z` 撤销，`Ctrl+Shift+Z` 或 `Ctrl+Y` 重做。

## 4. 审阅进度

- 可随时导出审阅进度文件，内含两份文档的指纹和每处选择（决定 12）。v0.5 起格式版本为 2，记录逐处选择；版本 1 的文件仍可载入。
- 再次上传同样两份文件并载入进度文件后，恢复所有选择。文件指纹不一致时，拒绝载入并说明原因。
- 差异编号按内容生成：同样两份文件再比较，编号不变。引擎版本变化（例如 engine-4）后，旧进度可能部分无法恢复。
- 存在未导出的选择时，离开或关闭页面前提示。
- 每次选择后自动保存一份到浏览器本地存储，作为辅助（决定 16，A11）。再次打开同样两份文件时，询问 “Restore your previous choices?”。本地存储可能被清空，不作为唯一保存手段。

## 5. 已知局限

- 发布在 claude.ai Artifacts 上的版本中，“Save progress” 和 Export 通过 Artifacts 的下载许可保存文件，保存前会弹出确认框。
- `?mock` 模式下导出是模拟的；mock 的文件“指纹”是对 mock 内容的哈希。
