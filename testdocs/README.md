# 测试文档

`docs/` 下是成对的旧版／新版 `.docx`，由 `build_testdocs.py` 生成（仅用 Python 标准库，直接写 OOXML）。重新生成：

```bash
python3 testdocs/build_testdocs.py
```

全部 14 个文件已通过 OOXML XSD 校验，但**尚未在 Windows Word 中实际打开检查**。请在公司电脑上用 Word 打开确认一次，尤其是 04（已有修订）和 05（批注、脚注、分节）。

每组的“期望结果”是本工具应该表现出的行为，也是后续自动化测试的依据。标 **【待定】** 的条目还需要讨论决定，见 `../docs/design-review-v0.1.md`。

## 07-long-document 长文档性能

60 章，约 3600 个段落（含表格单元格），60 张表，Word 中约 150 页以上。随机但可复现的改动：40 处词修改、10 处插段、10 处删段、2 处移动、10 处单元格修改、3 处插行。每处改动见 `07-long-document_changes.txt`，可直接作为召回率检查清单。
