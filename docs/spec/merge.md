# 合并模型

> 现行规则：用户怎么对差异做选择，最终结果怎么算。
> 移动内容的选择规则见 [comparison.md](comparison.md) §3；选了旧版之后文件怎么改，见 [export.md](export.md)。

## 1. 差异片段与选择

比较结果是一串按顺序排列、互不重叠的片段。每个片段要么“相同”，要么“差异”。一个差异片段，是旧版中的一段连续内容（可以为空）对应新版中的一段连续内容（可以为空）。

用户对每个差异片段选择采用旧版或采用新版：

| 差异类型 | 旧版一侧 | 新版一侧 | 采用旧版 | 采用新版 |
|---|---|---|---|---|
| 修改 | 有 | 有 | 用旧版内容 | 用新版内容 |
| 新增 | 空 | 有 | 不出现 | 出现 |
| 删除 | 有 | 空 | 出现 | 不出现 |
| 移动 | 原位置 | 新位置 | 放回原位置 | 留在新位置 |

**最终结果 = 按顺序拼接各片段的取值。** 相同片段原样保留，差异片段按选择取值。任何选择组合都有效，不存在选择之间的冲突。

“以新版为基础”只体现在两点：默认值是“采用新版”；导出时以新版文件为底稿修改。

## 2. 处理状态

- 每个差异片段有三种状态：**未处理**（按新版计算）、**已采用旧版**、**已采用新版**（决定 2）。可以逐处选择的段落（决定 42）还有第四种：**Mixed**——段内有的变化用旧版、有的用新版，算已处理；最终结果是新版段落，只把选了旧版的那几处换回旧版文字。各处都选了同一边时，自动变回整段的“采用旧版／新版”。
- 界面显示处理进度，例如“已处理 12／40”，并可跳到下一处未处理。进度的分母包含被隐藏的差异（A7）。
- 存在未处理项时仍可导出，导出前提示未处理数量。
- 选择记录支持撤销和重做；一次批量操作是一步撤销。
- 已选择的差异可以恢复为未处理（Mark unreviewed，决定 21）。
- 原始差异与用户的选择分开记录。改变选择后，差异仍可定位，可随时改主意。
- 只做提示的差异（例如可选比较项打开后的差异）不可选择，单独编号 #i1、#i2…（A8），始终按新版计入结果。

## 3. 不可采用旧版的片段

旧版内容中的某些元素引用的是旧版文件内部的编号和关系（脚注编号、关系 ID、编号 ID），直接带入新版文件可能导致引用失效，或者 Word 报“文件已损坏”。

Stage 3 的规则（决定 5、15）是：旧版或新版任一侧含脚注、图片、超链接、域、文本框、嵌入对象，就不能采用旧版。Stage 5 起（决定 43）改为只看**旧版一侧**能否安全写进新版文件（新版一侧的内容只是被删掉，不会出问题）：

| 旧版一侧含有 | 采用旧版 | 说明 |
|---|---|---|
| 普通文字、上下标、制表符、软回车 | 可以 | |
| 超链接 | 可以 | 链接地址复制进新版 |
| 域（交叉引用、日期、页码、SEQ…） | 可以 | 引用书签的域（REF、PAGEREF、NOTEREF），书签必须在新版中也存在；引入外部文件的域（INCLUDETEXT、INCLUDEPICTURE、LINK…）不可以 |
| 脚注、尾注 | 可以 | 新版必须有脚注（尾注）部件；脚注里含图表、文本框、嵌入对象时不可以 |
| 嵌入的图片 | 可以 | 链接到外部文件的图片不可以 |
| 公式 | 可以 | |
| 图表、形状、SmartArt、文本框、嵌入对象、嵌入文档 | 不可以 | 牵涉多个部件，写回出错的代价大 |

- 不可以时照常显示差异，“采用旧版”不可用并说明原因。
- 域或内容控件的起止跨越片段边界时，该片段不可采用旧版，并说明原因。
- 表格列或合并单元格结构变化：只能整表采用旧版。
